## ✨ Features

- **Dark Mode Aesthetic**: Deep purple gradient background with glassmorphism UI elements.
- **Hero & Tabbed Interface**: Interactive tab switching for Bio and Contact information.
- **Tech Stack Grid**: Visual skill badges rendered via Devicon CDN.
- **Career Timeline**: Clean vertical layout showcasing professional and academic experience.
- **Project Showcase**: Interactive work cards featuring dynamic status completion rings and smooth hover animations.
- **Lightweight & Fast**: Built with pure CSS/JS, requiring no heavy build frameworks.

## 🛠️ Built With

- **HTML5** & **Vanilla JavaScript**
- **Tailwind CSS** (via CDN)
